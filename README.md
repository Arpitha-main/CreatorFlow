# ✨ CreatorFlow – Creator Management Dashboard

**CreatorFlow** is a web-based dashboard designed to help content creators and influencers manage their professional activities in one place. It provides an organized space to track brand collaborations, manage deals, monitor payments, organize tasks, and keep track of important deadlines.

The project features a clean, modern lavender-themed interface designed to make creator management simple and convenient.

## 🚀 Features

- **Dashboard Overview** – View important creator activity and statistics.
- **Brand Deal Management** – Add, edit, and delete brand collaboration details.
- **Payment Tracking** – Monitor total earnings, received payments, and pending payments.
- **Task Management** – Create, update, delete, and track tasks.
- **Deadline Tracking** – Keep track of upcoming campaign deadlines and payments.
- **Calendar View** – View important events and scheduled activities.
- **Growth Overview** – Visualize monthly performance and growth.
- **User Authentication** – Login and sign-up functionality.
- **Profile Customization** – Update your display name and profile picture.
- **Responsive Design** – Access the dashboard across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, animations, and responsive design.
- **JavaScript** – Interactive features and dashboard functionality.
- **Local Storage** – Store user and dashboard data in the browser.
